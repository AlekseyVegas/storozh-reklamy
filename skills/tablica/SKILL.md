# Таблица для Сторожа рекламы

Задача: получить таблицу, которую Сторож читает без ошибок. Либо проверить существующую и перечислить правки, либо выдать шаблон с нуля. Полные правила и шаблон — в `references/pravila-tablicy.md`.

## Если таблица уже есть

1. Попроси скриншот первых 3–5 строк и 2–3 последних заполненных строк или выгрузку (CSV, Excel).
2. Проверь по правилам из `references/pravila-tablicy.md`:
   - в строке 1 — названия направлений над первой колонкой каждого блока;
   - в строке 2 — у каждого направления колонки «Бюджет…», «Показы», «Клики», «Лиды»; порядок внутри блока не важен, важно, чтобы каждый блок начинался с «Бюджет»;
   - в столбце A — даты в одном формате, настоящими датами, а не текстом;
   - строка итога («Тотал») считается через `SUMIF` по датам, а не ссылками на месячные подытоги;
   - будущие строки содержат только даты, без протянутых цифр (признак протяжки — дробные показы вроде 1 996,47).
3. Выдай список правок: что не так, где, как исправить. Самые опасные — первыми: текстовые даты, протянутые цифры, «Тотал» с ручным перечислением.
4. Направления с нестандартной разметкой (например, воронка игры вместо лидов) не ломают Сторожа: он их перечислит в отчёте как «не распознаны». Скажи об этом и предложи либо добавить колонку «Лиды», либо внести направление в список исключений.

## Если таблицы нет

1. Спроси названия направлений (лендинги, кампании, площадки) и примерный объём: сколько направлений.
2. Выдай шаблон по `references/pravila-tablicy.md`: шапку, формулы и первую строку-пример. Если в сессии есть инструменты для файлов, собери файл .xlsx или .csv с шапкой и формулами, чтобы пользователь загрузил его в Google Таблицы (Файл — Импорт).
3. Объясни, что руками вносятся только 4 колонки в день: бюджет, показы, клики, лиды. Остальное считают формулы.

## Когда таблица готова

Предложи следующий шаг: пороги по цифрам прошлого месяца (навык `porogi`) или сразу скрипт (навык `skript`).

## Чего не делать

- Не выдумывай цифры для примеров как реальные данные пользователя. Примеры помечай как учебные.
- Не советуй протягивать цифры мышкой в будущие дни.
