# Правила таблицы для Сторожа рекламы

## Структура

Один лист. По умолчанию Сторож читает первый лист таблицы; другой лист задаётся в настройке `SHEET_NAME`.

**Строка 1 — названия направлений.** Название стоит над первой колонкой блока. Остальные ячейки блока пустые или объединённые, неважно. Название может быть ссылкой: `https://site.ru/traffic/`.

**Строка 2 — метрики.** У каждого направления свой блок. Рекомендуемый порядок:

`Бюджет, без НДС | Показы | Клики | Лиды | CPM | CPC | CTR | CR | CPL`

Сторож находит блок по колонке, название которой начинается с «Бюджет». Внутри блока (до следующего «Бюджет») ищет колонки, которые начинаются с «Показы», «Клики» (или «Переходы»), «Лиды» (или «Заявки», «Конверсии»). CPM, CPC, CTR, CR, CPL Сторож не читает: считает сам из сырых цифр.

**Строка 3 — «Тотал»,** итог за всё время. Необязательна.

**Дальше — по строке на день.** Строки без даты в столбце A (подытоги месяцев, пустые) Сторож пропускает.

## Пример

| Дата | Лендинг А | | | | | | | | | Лендинг Б | … |
|---|---|---|---|---|---|---|---|---|---|---|---|
| | Бюджет, без НДС | Показы | Клики | Лиды | CPM | CPC | CTR | CR | CPL | Бюджет, без НДС | … |
| Тотал | =SUMIF(…) | =SUMIF(…) | =SUMIF(…) | =SUMIF(…) | | | | | | | |
| 01.08.26 | 7 000 | 3 456 | 14 | 2 | формула | формула | формула | формула | формула | | |

Учебные цифры.

## Формулы

Руками вносятся 4 колонки: бюджет, показы, клики, лиды. Остальные — формулы (для строки 4, дальше протянуть вниз). Пример для блока B–J:

```
CPM (F4) = ЕСЛИОШИБКА(B4 / C4 * 1000; "")
CPC (G4) = ЕСЛИОШИБКА(B4 / D4; "")
CTR (H4) = ЕСЛИОШИБКА(D4 / C4; "")
CR  (I4) = ЕСЛИОШИБКА(E4 / D4; "")
CPL (J4) = ЕСЛИОШИБКА(B4 / E4; "")
```

В английской версии Google Таблиц: `IFERROR`, разделитель запятая.

## Строка «Тотал»

Только так, в первые четыре колонки каждого блока:

```
=SUMIF($A$4:$A$1000; ">0"; B$4:B$1000)
```

Формула складывает строки, где в столбце A стоит настоящая дата. Не пишите `=SUM(B50; B82)` со ссылками на подытоги месяцев: добавите месяц, забудете дописать — итог начнёт тихо врать.

CPM, CPC, CTR, CR, CPL в строке «Тотал» считайте делением итогов, а не суммой.

## Даты — самое хрупкое место

1. **Один формат на весь столбец:** `05.08.26`. Не смешивайте с `5 августа` и `2026-08-05`. Сторож понимает и дату, и текст `05.08.26`, но единый формат спасает от путаницы.
2. **Дата должна быть датой, а не текстом.** Проверка на глаз: настоящая дата прижимается к правому краю ячейки, текст — к левому. Исправление: выделить столбец A — Формат — Числа — Дата.
3. **Строка на день должна существовать заранее.** Нет строки — нет отчёта, Сторож пришлёт предупреждение. Даты вперёд добавляет команда «Дозаполнить даты» в меню Сторожа.

## Не протягивайте цифры в будущее

Заполняйте будущие строки только датами. Если протянуть цифры мышкой, Google Таблицы достроят правдоподобный ряд, и Сторож отчитается по выдуманным числам как по факту. Признак протяжки — дробные показы или клики: 1 996,47. Пустая ячейка честнее нарисованной.

## Числа

Числа лучше вносить числами. Если в ячейке текст вида `1 801` или `7 000 ₽`, Сторож его прочитает, но формулы таблицы — нет.

## Нестандартные направления

Если у направления нет колонки «Лиды» (например, воронка игры: «Начало», «Сцена 1», «Финал»), Сторож не проверяет его и пишет в конце отчёта «Не распознаны: … (нет колонок: лиды)». Направление не выпадает молча. Варианты: добавить колонку «Лиды» с главной целевой конверсией или внести направление в `SKIP_DIRECTIONS`.
